# osm-bzh-kartenn

Visualiseur cartographique du service de tuiles OpenStreetMap en langue bretonne
(https://tile.openstreetmap.bzh/br/), basé sur [mviewer](https://github.com/mviewer/mviewer) v4.1.

- Configuration de l'application : `apps/default.xml`
- Test en local : `python3 -m http.server 8099` puis http://localhost:8099/
- mviewer est sous licence GPL (voir `LICENSE.mviewer`, `CREDITS.mviewer`).
